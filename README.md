# Astro website architecture

The production site is generated by Astro as static HTML.

## Reusable source

- `src/layouts/BaseLayout.astro` — shared HTML document and SEO tags
- `src/components/Header.astro` — shared navigation and active state
- `src/components/Footer.astro` — shared footer, social links, and WhatsApp button
- `src/components/ProjectCard.astro` — company portfolio card
- `src/components/ReferenceCard.astro` — building reference card
- `src/data/projects.mjs` — project data source
- `src/data/routes.json` — migrated page content and metadata

Homepage and Portfolio use data-driven Astro components. Other routes share the same layout, header, footer, and SEO rendering while retaining their existing page-specific content.

## Commands

```bash
npm install
npm test
npm run build
```

Deploy only `dist/` to the Nginx document root. Root-level legacy HTML files are retained as migration inputs/rollback material and are not deployed by the Astro release process.

When a legacy content page changes, run:

```bash
npm run migrate
npm test
```
